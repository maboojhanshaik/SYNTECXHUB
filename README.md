## 📅 Week 1

### Project 1 — Blood Cancer Dataset Analysis (NumPy)
- Loaded and explored a hematological/clinical dataset using **NumPy**.
- Extracted and converted key numerical columns (e.g., age) for analysis.
- Performed basic statistical computations (mean, shape, column-level summaries) on numerical data.
- **Tools:** Python, NumPy
- **Files:** `Blood_Cancer.py`, `blood_cancer.ipynb`, `Blood_Cancer_Diseases_dataset.csv`

### Project 2 — Portuguese Bank Marketing Analysis
- Analyzed a bank marketing dataset (`bank-additional`) using **Pandas**.
- Explored data structure with `.info()`, `.describe()`, `.head()`, and `.tail()`.
- Filtered and segmented customers based on:
  - Age (customers aged 50+)
  - Housing loan status
  - High marketing campaign contact frequency (>5 contacts)
- Exported filtered customer segments to CSV/Excel for reporting.
- **Tools:** Python, Pandas
- **Files:** `Portuguese bank.py`, `Portuguese bank.ipynb`, `customers_above_50.csv/.xlsx`

### Project 3 — Netflix Titles: EDA & Data Cleaning
- Performed exploratory data analysis on the Netflix titles dataset.
- Handled missing values using `SimpleImputer` from **Scikit-learn**.
- Cleaned and standardized the dataset, producing a cleaned output file and a cleaning log.
- **Tools:** Python, Pandas, NumPy, Scikit-learn
- **Files:** `Netflix.ipynb`, `netflix_titles.csv`, `netflix_titles_cleaned.csv`, `cleaning_log_advance.csv`

## 📅 Week 2

### Project 1 — UK Retail Sales Index Analysis & Visualization
- Analyzed the **UK Retail Sales Index (RSI)** dataset to track retail trends over time.
- Generated a quarterly summary and tracked the **Average Food Index** and **Online Shopping Share**.
- Created visualizations including:
  - Sales trends over time
  - Category-wise comparisons
  - Online vs. in-store shopping share (pie chart)
- **Key Insight (Jan 2026 snapshot):** Average Food Index of **79.74**, with online shopping accounting for **28.9%** of total retail sales.
- **Tools:** Python, Pandas, Matplotlib, Seaborn
- **Files:** `Retail Sales Index.ipynb`, `drsi.csv/.xlsx`, `quarterly_summary.csv`, `summary.txt`, chart images (`.png`/`.jpeg`)

## 📅 Week 3

### Project 2 — Netflix Visual Analytics & Reporting
- Built on the Week 1 Netflix EDA with deeper visual analysis and a final summary report.
- Analyzed a dataset of **5,806 titles** (3,759 Movies / 2,047 TV Shows).
- Key findings:
  - **Most productive year:** 2019 (848 titles released)
  - **Average movie duration:** 98.79 minutes
  - **Top genre overall:** Drama
  - Identified a 10-year release trend (2013–2022), showing peak content output around 2018–2021.
- Produced a consolidated visual report and written summary.
- **Tools:** Python, Pandas, Matplotlib
- **Files:** `Netflix.ipynb`, `raw_titles.csv`, `netflix_visual_report.jpeg`, `summary_report.txt`

## 📅 Week 4

### Project 2 — IPL Cricket Data Analysis
- Performed end-to-end analysis of **IPL (Indian Premier League)** match and ball-by-ball data.
- Analyzed **1,169 matches** to uncover season trends and player/team performance.
- Key findings:
  - **All-time leading run scorer:** V Kohli
  - **Highest team win rate:** 61.67% (Team ID 615)
  - Visualized total run evolution across seasons, player-vs-player run comparisons, team win rates, and top all-time IPL run scorers.
- **Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn
- **Files:** `IPL Data Analysis.ipynb`, `ipl_matches_data.csv`, `ball_by_ball_data.zip`, `ipl_analysis_summary.csv`, chart images (`.jpeg`)
